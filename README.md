# Hermes Agent 2.0 — Материалы

Коллекция файлов и шаблонов из видео-гайда по Hermes Agent 2.0.

## Файлы

| Файл | Описание |
|------|----------|
| `soul_template.md` | Шаблон SOUL.md для настройки личности агента |
| `docker-compose.yml` | Конфигурация Docker для Hermes |
| `env_template.txt` | Шаблон .env с переменными окружения |
| `hooks_template.yaml` | Шаблон хуков безопасности |
| `telegram_команды.md` | Все команды для Telegram-интерфейса |
| `промт_для_docker.txt` | 12-шаговый промт для развёртывания в Docker |
| `промты_10_автоматизаций.md` | 10 готовых крон-задач "Chief of Staff" |
| `ссылки_и_материалы.md` | Ссылки и ресурсы из видео |
| `Hermes_Agent_2.0_гайд.pdf` | Полный PDF-гайд |

## Быстрый старт

1. Скопируй `env_template.txt` в `~/.hermes/.env` и заполни ключи
2. Используй `docker-compose.yml` для запуска
3. Настрой `soul_template.md` под себя и сохрани как `~/.hermes/SOUL.md`
